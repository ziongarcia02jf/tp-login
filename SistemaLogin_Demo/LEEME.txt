SISTEMA LOGIN - DEMO ESCOLAR

==================================================
1) CÓMO PROBARLO
==================================================
Hacé doble clic en: SistemaLogin.exe

Ingresá con una de estas cuentas:

ADMINISTRADOR
  Usuario:    admin
  Contraseña: admin123
  Respuestas: firulais / buenos aires / san martin

USUARIO COMÚN
  Usuario:    usuario
  Contraseña: usuario123
  Respuestas: luna / cordoba / belgrano

Después de la contraseña, el sistema pide las 3 preguntas de seguridad.

Con la cuenta de administrador podés:
  - Ver la lista de usuarios.
  - Agregar usuarios nuevos.
  - Eliminar usuarios.
  - No se puede eliminar al último administrador.

==================================================
2) CÓMO ABRIR EL CÓDIGO
==================================================
Entrá a la carpeta "Codigo" y abrí:

  SistemaLogin.sln

Con Visual Studio 2012, presioná F5 para ejecutar.

==================================================
3) DÓNDE SE GUARDAN LOS DATOS
==================================================
%AppData%\SistemaLogin\usuarios.xml

Para reiniciar la demo:
  1. Cerrá el programa.
  2. Borrá la carpeta %AppData%\SistemaLogin
  3. Volvé a abrir SistemaLogin.exe

Se vuelven a crear las cuentas de demostración.

==================================================
4) REQUISITOS
==================================================
Windows con .NET Framework 4.5 o superior.
No hace falta instalar nada más para ejecutar el .exe.
